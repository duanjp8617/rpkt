# Checked batch and SIMD classification experiment

The `batch` feature adds caller-owned output and per-packet errors/fallbacks.
It is not selected automatically and is not advertised as a speedup.
`parse_common` caches validated offsets/fields in an immutable borrow;
`parse_general` handles VLAN/options. Fragments and split headers remain explicit
fallbacks. Neither path verifies checksums or reassembles packets.

Three runs on tg, Xeon Gold 6230, CPU 2, Rust 1.98, portable target, committed
lockfile, fat LTO and one codegen unit; 20 samples, 100 ms warmup, 200 ms measurement:

```sh
taskset -c 2 cargo bench --locked -p benches --bench matrix --features batch -- \
  'batch/largefalse/mixed(false|true)/(general_loop|checked_batch|avx2_pack)/(1|32)$' \
  --noplot --nresamples 1000
```

Median central estimates from three runs, ns/batch (divide by batch size for
ns/packet). Inputs are 64-byte frames; mixed cases include VLAN, options,
truncation and another transport. All paths produce the same successful fields
and classify destination port 4321; malformed-status detail differs. Input-view
packing, output writes, lane packing and bit-mask conversion are timed.

| Traffic | Batch | General loop | Checked batch | Batch + AVX2 packing |
| --- | ---: | ---: | ---: | ---: |
| Common UDP | 1 | 19.56 | 26.50 | 31.06 |
| Common UDP | 32 | 407.85 | 650.75 | 651.44 |
| Mixed | 1 | 17.52 | 24.67 | 27.87 |
| Mixed | 32 | 365.94 | 573.71 | 566.88 |

The production API remains scalar. The benchmark-only AVX2 packing experiment
is retained to reproduce the negative result; it is guarded by runtime feature
detection. No SIMD gather backend is shipped. Forcing the common/general helper
to inline did not improve the local comparison and was removed. Assembly showed
view/result stack traffic; the existing scalar loop is still the recommended
throughput path for this workload. No speedup is claimed from cached fields alone.

The complete matrix also exercises batches 4/8/16/64 and 16 MiB working sets.
The batch API passes native tests, Miri, bare-metal compilation, all header
segment splits, invalid lengths and order/partial-output checks. Fuzzing the
common/general relationship completed 4,463,952 executions in a 31-second smoke.
