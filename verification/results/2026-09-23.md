## Regression discovered

`bytes::Buf` requires `chunk().is_empty()` if and only if `remaining() == 0`.
Before the fix, constructing a Pbuf from two empty segments followed by
`[1, 2, 3]` returned an empty chunk with nonzero remaining length.

The new `empty_segments_preserve_the_buf_progress_contract` test failed under
Miri before changing the constructor:

```text
assertion `left == right` failed
  left: []
 right: [1, 2, 3]
```

It passes after initial empty-segment skipping. The strengthened formal model
also rejects removal of its corresponding normalization step. This is a
buffer-contract/progress bug; the failed assertion is not itself a demonstrated
out-of-bounds memory access.
